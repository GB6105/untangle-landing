# 핵심 규칙 요약

| ID | 규칙 |
| --- | --- |
| GH-1 | 브랜치 생성·커밋·push·PR 생성/병합 등 **모든 git 쓰기 작업은 실행 전에 사용자에게 내용을 제시하고 승인을 받는다.** 승인 없이 실행하지 않는다. |
| GH-2 | `main`에 직접 커밋·push 하지 않는다. 항상 기능 브랜치에서 작업하고 PR로 병합한다. |
| GH-3 | 커밋·PR 본문은 **한국어**로 쓴다. |

# 1. Git Branch

### 이름
- `<구분>/<짧은-설명>` 형식.
  - 브랜치 `<구분>/<짧은-설명>`은 영어로 작성
  - 구분: `feat`, `fix`, `docs`, `refactor`, `chore`
  - 예: `feat/hero-section`, `fix/mobild-nav`, `docs/github-workflow`

### 분기 기준
- 사용자가 따로 명시하지 않았다면 브랜치는 최신 `main`에서 분기한다.

# 2. Git Commit

### 제목
- `접두어: <메시지>` 형식
- 접두어는 아래 표를 참고하고, 메세지는 한국어로 작성

| 접두어 | 사용 |
| --- | --- |
| `feat` | 기능 추가·변경 |
| `fix` | 버그 수정 |
| `docs` | 문서 변경 (`docs/`, `README`, `AGENTS.md`) |
| `refactor` | 동작 변화 없는 코드 구조 개선 |
| `chore` | 의존성·설정·빌드 등 (`pyproject.toml`, `uv.lock`, `.gitignore`) |

### 본문

- 메시지 본문은 전부 한국어로 쓴다.
- 제목은 요약형으로 한 줄. 바뀐 코드 중에 가장 중요하다고 생각하는 변경 사항이 드러나게 적는다.
- 본문에는 변경 내용을 한국어로 서술한다.


### 예시

**`feat` — 기능 추가**

```
feat: 히어로 섹션 반응형 레이아웃 추가

데스크톱·태블릿·모바일 브레이크포인트에 맞춰 히어로 섹션을 재구성한다.
모바일에서는 CTA 버튼을 전체 너비로 표시하고 이미지를 하단에 배치한다.
```

**`fix` — 버그 수정**

```
fix: 모바일 내비게이션 토글 오류 수정

햄버거 메뉴를 연 뒤 스크롤하면 메뉴가 닫히지 않던 문제를 수정한다.
바깥 영역 클릭과 라우트 변경 시 메뉴 상태를 초기화하도록 변경한다.
```

**`docs` — 문서 변경**

```
docs: README에 로컬 실행 방법 추가

프로젝트 클론 후 의존성 설치와 개발 서버 실행 순서를 README에 정리한다.
환경 변수 설정 예시와 주요 스크립트 설명을 함께 추가한다.
```

**`refactor` — 구조 개선**

```
refactor: 버튼 컴포넌트 variant 구조 정리

primary·secondary·ghost로 흩어져 있던 스타일을 단일 Button 컴포넌트로 통합한다.
variant와 size를 props로 받아 Tailwind 클래스를 조합하도록 변경한다.
```

**`chore` — 의존성·설정·빌드**

```
chore: 빌드 설정 및 의존성 정리

미사용 패키지를 제거하고 남은 의존성을 최신 버전으로 업데이트한다.
package.json과 lock 파일을 동기화한다.
```


# 3. Github PR

- `gh` CLI를 사용하여 작업.
### 3.1 제목
- [`카테고리`] `한 줄 설명` 
- `카테고리`: 어디를 변경했는지 또는 어떤 기능을 건드렸는지 등의 이번 작업에서 주로 다룬 것을 짧은 단어로 표현
- `한 줄 설명`: 수행한 일을 간단하게 한 줄로 서술
- `카테고리`가 목적어라면 `한 줄 설명`은 서술어

### 3.2 본문
- `목적`: 무엇을 달성하기 위해서 이 작업을 수행했는지 핵심만 두 줄 이하로 설명
- `변경 사항`: **변경된 모든 내용을 적는게 목표가 아니며 목적을 달성하기 위해 수정 또는 추가한 내용이 무엇인지 다른 사람이 알 수 있게 해야 한다.**

### 3.3 예시
```
제목: [히어로 섹션] 반응형 CTA 추가

## 목적
서비스 진입 첫 화면에서 핵심 가치를 한눈에 전달하고,
주요 CTA 클릭으로 전환을 유도하기 위해 히어로 섹션을 추가한다.

## 변경 사항
- `sections/Hero.tsx` 추가: 헤드라인·서브카피·CTA로 구성한 히어로 섹션
- 데스크톱/태블릿/모바일 브레이크포인트별 반응형 레이아웃 적용
- 모바일에서 CTA를 전체 너비로 노출해서 쉽게 탭할 수 있게 변경
```

```
제목: [모바일 내비게이션] 메뉴 토글 오류 수정

## 목적
모바일에서 메뉴가 닫히지 않아 콘텐츠를 가리던 문제를 해결해 작은 화면에서의 탐색 흐름을 정상화한다.

## 변경 사항
- 메뉴가 열린 상태에서 스크롤·라우트 변경 시 자동으로 닫히도록 수정
- 바깥 영역(overlay) 클릭 시 메뉴를 닫는 핸들러 추가
- 메뉴 열림 동안 `body` 스크롤을 잠가 배경 스크롤 방지
```
